# 提前上屏参数基准（2026-10-23）

## 方法

- **语料**：`mohu_zrm.words.dict.yaml`（by_weight 头部高频段）随机抽样 150 条 4–12 字短语；每字取词表 rank-1 虎码（一简字改用次选 ≥2 键码，一简中途非法）。
- **仿真**：`tools/bench_early_commit.lua` 逐键驱动 `tiger_mode_proc`（真实引擎 + V5 模型），记录每笔自动提交；打完按空格收尾（末段取首选）。
- **指标**：
  - 误上屏句/误笔：任一笔提交后累计文本不再是目标前缀；
  - 收尾全对：累计自动提交 + 末段首选 == 目标短语；
  - 自动覆盖：自动提交字符占比；
  - 对照组关闭顶功（`tiger/push_commit: "false"`）。

## 结果（150 句）

| 设置 | 误上屏句 | 误笔 | 收尾全对 | 自动覆盖 | 均提交笔数 |
|---|---|---|---|---|---|
| 顶功 + 0.995 | 0 | 0 | 95.3% | 60.1% | 2.2 |
| 顶功 + 0.98 | 0 | 0 | 95.3% | 62.0% | 2.3 |
| **顶功 + 0.95（默认）** | **0** | **0** | **95.3%** | **62.8%** | **2.3** |
| 顶功 + 0.93 | 0 | 0 | 95.3% | 62.9% | 2.3 |
| 顶功 + 0.90 | 0 | 0 | 95.3% | 63.5% | 2.4 |
| 无顶功 0.995 | 0 | 0 | 94.7% | 51.9% | 1.4 |

## 结论

1. **顶功贡献主要覆盖**（+8~11pp），置信门槛在 0.90–0.98 区间只差 1–3pp 且全零误——门槛不敏感，取 **0.95** 默认（+2.7pp 覆盖，零误，且高于真实歧义句「不知首领是谁又是谁带他去的」错读族峰值 90.3%，该句安全窗实测 (0.903, 0.945]）。
2. 顶功 + 前 3 行边界一致规则把初版 3 句误上屏（一片哗然→一刮、七大姑八大姨→七大灵、一肚子坏水→一肚恨不）清零：误顶根源是一致性只看 items/early 首选两行、排名第 2 的正确读法不参与投票。
3. 收尾全对 95.3% 略高于无顶功 94.7%：提前提交正反馈（committed 链全串解码）在该语料上未损伤终局首选。

## 已知边界

- 四码字（≤3 键边界限制）与模型偏好分歧（哼族对中族）不顶，交给置信度路径。
- 门槛 <0.90 未测出误笔但逼近真实歧义峰值，不建议。

- **收尾全对 97.16%**。
