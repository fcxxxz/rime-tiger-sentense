# 虎整魔虎版 vs 官方虎整：随机句双臂对照（10,000 句，2026-11-11）

## 口径

- **虎整魔虎版（new）**：本仓原生引擎（libtigerengine + V5 字元三元模型 389MB）+
  虎整码表词表（data/tiger/tiger.lexicon.txt，由 lvyww codes.txt 生成）、
  all_ranks=false（定顶）、提前上屏出厂默认——即当前装机/发布包配置
- **官方虎整（lvyww）**：lvyww/tiger-sentense-rime 官方发布包 20260915-3dd98bd
  （TCSKNM02 三阶 224MB；HEAD 五阶未随 Release 公开）
- 两臂码表**同源**（共同 rank-1 字 9,239），同码流逐句配对
- 语料：fenci 池 4,246 万句（共同字全集可编码），seed 20261111 抽 10,000 句，
  296,811 键；训练重叠口径（语料与 V5 训练同源）
- 内存：每分片独立 lua 进程 `/usr/bin/time -l` 最大驻留集（RSS）
- 性能：逐键处理器 CPU（os.clock，抽样 1/4 键）

## 结果

| 指标 | 虎整魔虎版 | 官方虎整 | 差值 |
|---|---:|---:|---:|
| 最终首选准确率 | **99.55%** | 98.07% | **+1.48pp** |
| 配对（仅本方正确） | **180** | 32 | — |
| 错误提前上屏事件 | **19** | 51 | −62% |
| 上屏率（自动上屏字符覆盖） | **86.96%** | 59.79% | **+27.16pp** |
| 句均上屏次数 | **8.75** | 5.99 | +2.76 |
| 每键上屏率 | **29.48%** | 20.18% | +9.29pp |
| 残留码长（打完瞬间，键） | **4.06** | 12.33 | −8.27 |
| 残留字数（打完瞬间） | **1.64** | 5.07 | −3.43 |
| 每键 CPU 均值 | **1.94ms** | 5.23ms | **2.7×** |
| 每键 CPU P50 | **0.23ms** | 4.39ms | 19× |
| 每键 CPU P99 | **14.6ms** | 18.2ms | −20% |
| 分片 RSS 均值 | 361MB | **80MB** | +281MB |
| 空闲足迹（停打 3 秒后） | **35MB** | ~80MB | −45MB |

## 读法

- **准确率**：99.55% vs 98.07%，配对 180:32——147 句净差，同码流同句集，
  差距全部来自解码与排序（码表同源，无码表差异混杂）。
- **上屏节奏**：提前上屏引擎平均每句自动提交 8.7 次（≈每 1.2 字一次），
  打完瞬间只挂 4 键 1.6 字；官方版分别 6 次、12.3 键 5.1 字——句尾需要
  更长的确认/手工收尾。每键上屏率 29.5% vs 20.2%：约每 3.4 键就有一次
  自动落字。
- **性能**：均值 2.7×，P50 差 19×（C++ 引擎 + 缓存 vs 纯 Lua 五候选拼装）；
  P99 本方 14.6ms 仍受长句首键重解码影响，但低于对方。
- **内存两层结论（2026-11-11 空闲修剪落地后）**：
  1. RSS 口径 361MB 是**打字中**被摸热的干净文件页——macOS `phys_footprint`
     口径下模型页贡献为 **0**（OS 可回收页缓存，内存压力实测不计入），
     引擎真实驻留只有几十 MB；
  2. 引擎新增**模型页空闲修剪**（`TIGER_MODEL_TRIM_SEC`，默认 3 秒）：
     停打 3 秒后释放全部 mmap 热页——macOS 用 munmap+MAP_FIXED 原址重映射
     （madvise 三变体实测对文件页无效），Linux 用 DONTNEED。实测
     239MB→**35MB**（优于官方常驻 80MB），恢复打字首键一次性回填 +5.9ms
     无感、后续键不受影响；连续打字不触发，基准准确率/延迟零扰动
     （复跑 99.55% / 1.84ms 持平）。`probe_trim.lua` 可复现。

## 上屏率阈值扫描与归因（2026-11-11 追加）

门槛 `tiger/early_commit_threshold` 扫描（1 万句，其余条件同主表）：

| 门槛 | 上屏率 | 误提前上屏 | 错句 |
|---|---:|---:|---:|
| 0.99（现行） | 86.96% | 19 | 45 |
| 0.97 | 87.25% | 34 | 48 |
| 0.95 | 87.40% | 46 | 48 |
| 0.90 | 87.57% | 50 | 51 |

降门槛只 +0.6pp 换误提前 2.6×——纯赔本，维持 0.99。

**13.04% 未上屏的归因：100% 是句尾**（均挂 1.64 字；61% 的句子只挂 1 字、
31% 挂 2 字），句中零停滞。这是证据型提前上屏的物理边界：最后 1~2 字没有
后续键做确认证据。真实连续打字时下一句首键会自动把尾巴顶出（continuation），
只有段尾需要一次空格；基准为孤立句打完口径。对照：官方虎整句尾挂 5.07 字。

错句对照明细见 `errors-paired.tsv`（我方 45 / 官方 193 / 同错 13）。
我方独有错误集中在「长词末字被同码字吃」（网站→网点×3、供电→放电、
甲板→从板、流量→流事）——字元三元无词级先验的短板，后续以词表先验攻。
